# Cloud-Based Log Monitoring System

A cloud-enabled log aggregation and anomaly detection platform using Python and Flask. Collects logs from Docker containers, visualizes real-time metrics, and supports CI/CD automated deployment.

## Features
- Aggregates logs from multiple Docker containers.
- Real-time metrics visualization with Flask web dashboard.
- Anomaly detection to identify unusual log patterns.
- CI/CD pipelines using Jenkins for automated deployments.
- Cloud deployment on AWS EC2 and S3 for high availability.

## Tech Stack
- **Languages:** Python 3
- **Frameworks:** Flask
- **DevOps:** Docker, Jenkins, AWS EC2 & S3
- **Monitoring:** Custom dashboards for log metrics
